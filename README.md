## Contexto :

O rapaz que achou a bandeira agora tem um problema, o problema é: havia um mito sobre aquela bandeira, aonde um Rei mago havia feito um feitiço nela e este feitiço fazia com que todos se virassem contra você.


## As ações do jogador
Ações:
W / ↑	Mover para cima
S / ↓	Mover para baixo
A / ←	Mover para a esquerda
D / →	Mover para a direita
Espaço : atira 
B : coloca um avião para te ajudar por 100 dinheiro tap
E : Tiro extra
P : vai para o mundo dois

## 5  Inimigos e/ou obstáculos: tipos, comportamento (parado, patrulha, persegue o jogador, atira, etc.)
inimigos: homens que atiram ( atiram/ perseguem o jogador )

avião (perseguem o jogador)

## 6 Itens e coletáveis: moedas, power-ups, chaves, vidas extras. O que fazem quando coletados?

Os coletáveis são: dinheiros taps que funciona para mecanismo de troca


## 7 condições de vitória:

ir pro mundo dois e terminar ele.


## 8 Condições de derrota:

Se ele perder todas vidas.

## 9 Progressão/dificuldade: o jogo tem fases? Fica mais difícil com o tempo? Existe algum sistema de pontuação ou recorde?

O jogo não fica mais difícil com o tempo, conforme as ordas passam
